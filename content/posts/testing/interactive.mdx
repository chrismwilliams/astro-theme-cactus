## alg: none vẫn còn sống

Nghe thì cổ điển, nhưng vẫn có thư viện tự build cho phép `alg: none`. Vấn đề không nằm ở JWT mà ở chỗ server để client quyết định cách verify chữ ký.

```ts title="verify.ts"
// ❌ đừng làm thế này
const payload = jwt.verify(token, key);
// ✅ pin thuật toán
const payload = jwt.verify(token, key, { algorithms: ["RS256"] });
```

## kid injection

Header `kid` thường được dùng để tra key từ file system hoặc database. Nếu không validate, đây là entry point cho path traversal hoặc SQL injection.

### Cách phát hiện

Thử `kid: ../../dev/null` và ký token bằng chuỗi rỗng.
